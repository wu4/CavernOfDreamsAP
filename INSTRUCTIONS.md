# Installation Instructions

1. Install [BepInEx](https://github.com/BepInEx/BepInEx/releases) for your OS by extracting the appropriate .zip/.tar.gz into the directory containing CavernofDreams.exe. (On Windows. this is probably C:/Program Files (x86)/Steam/steamapps/common/Cavern of Dreams)
2. Open the game, then close the game. This generates the other BepInEx subfolders you need.
3. Download [the plugin](https://github.com/wu4/CavernOfDreamsAP/releases) and extract it into the BepInEx/plugins folder (so the hierarchy goes /plugins/Archipelago).
4. Install the latest [.apworld file](https://github.com/wu4/Archipelago/releases/tag/v0-beta.10.3).
5. Open the game.
